# Subtitle-Generator-and-Summarizer - Project
An NLP tool that converts video lectures into subtitles (.srt) and short summaries using OpenAI Whisper for transcription and BART/FLAN-T5 for summarization — making learning faster and more accessible.
An NLP-powered tool that automatically generates subtitles (.srt) and concise summaries from video lectures — designed to improve accessibility and save students' revision time.
What it does

Downloads YouTube lecture videos and extracts audio using yt-dlp and moviepy
Applies noise reduction and transcribes speech to text using OpenAI Whisper
Generates timestamped .srt subtitle files from transcripts
Summarizes long lectures into 3–5 sentences using BART / FLAN-T5 transformer models
Evaluates quality using WER (transcription) and ROUGE score (summarization)

🛠️ Tech Stack
Python · OpenAI Whisper · HuggingFace Transformers · BART / FLAN-T5 · MoviePy · yt-dlp · PyTorch · ROUGE · WER
